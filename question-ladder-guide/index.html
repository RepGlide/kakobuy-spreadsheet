Question Ladder Guide

From the category to the next click — what to answer at each of the four rungs, one question per click.

Climb one rung at a time

A broad label is a starting point, not an answer. The question ladder turns a vague clue into four separate questions, and asks you to answer only one at a time.

Rung 1 — Category

Which category am I browsing? The category chooses which questions apply next. A bag raises different questions than a watch or a jersey. Settle this first, and only this.

Rung 2 — Visible option

Which exact option does the current page show? Read what is literally on the page — the color, size, version, or quantity it displays right now. Not the option you remember from the row, and not the one you assume.

Rung 3 — Missing detail

Which important detail is still missing? If the page does not show the currency, the sizing, the material, or the shipping method, write that gap down. A missing detail is a question, not a failure.

Rung 4 — Confirmation place

Where should this question be re-confirmed? Name the destination that can actually answer it. If a fact cannot be confirmed from this page, it belongs to an external place — and that is where you re-check it.

A worked ladder

  1. Category: the clue is a bag.
  2. Visible option: the page shows the bag in black with a size list.
  3. Missing detail: the material is not stated on the page.
  4. Confirmation place: the material must be re-checked on the target product page.

Teaching example — not saved, personalized, or product verification.

When to stop

If the next click cannot answer the question you are holding, pause. Record the gap and mark it as unknown or not knowable from this page. Do not guess the answer and keep climbing as if you had found it.
